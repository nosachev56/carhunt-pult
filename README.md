# carhunt-pult

Пульт управления сервером проекта CARHUNT.

Здесь нет кода проекта — только механизм запуска. Задания забираются из
закрытого репозитория на время выполнения и внутрь этого репозитория не
попадают.

## Как пользоваться

Вкладка **Actions** → «Задание на сервере» → **Run workflow**. Ввести имя
задания (`osmotr`, `podgotovka`, `nastroyka`) и ветку закрытого репозитория.

Запуск только вручную и только у владельца репозитория. Автоматического
запуска по событиям нет намеренно.

## Секреты

| Имя | Что это |
|---|---|
| `SERVER_HOST` | адрес сервера |
| `SERVER_PASSWORD` | пароль root |
| `REPO_TOKEN` | токен только на чтение закрытого репозитория |

Значения секретов GitHub не показывает никому, включая владельца, и не
передаёт в ответвления.

## Что видно в журналах

Журналы выполнения открыты всем. Задания намеренно не печатают адрес
сервера, имя машины и пароли. Видны версии пакетов, свободное место и
таблица доступности внешних адресов.
